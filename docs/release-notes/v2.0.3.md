## 2.0.3

### Approval handling

- Core now publishes explicit truthful MCP annotations instead of leaving several tools on unknown
  defaults. Arbitrary shell execution remains destructive/open-world rather than being mislabeled.
- Bounded `find` remains available beside command execution, `copy_file` handles exact create-only
  backups, and `poll_command` waits for output without writing to the child process.
- These safe primitives give ChatGPT the scope metadata needed to honor the connector-specific
  **Allow all actions** setting for routine work. The host may still confirm genuinely high-risk
  shell or process-input actions.

### Compatibility

- The Core action list now includes `copy_file` and `poll_command`. Refresh/review the custom app in
  ChatGPT and start a new conversation after updating so the new schemas are discovered.
- Read-only mode and disabled capabilities continue to reject the corresponding operations at the
  handler even when an older ChatGPT tool snapshot is still cached.

> Beta despite the version number. Behaviour may still change between releases.
